# 2027 수능 대비 예상 모의고사 (무료) 예비 받기 경로

이 저장소는 **2027 수능 대비 예상 모의고사** 파일을 받는 **예비 경로**입니다.
기본 안내와 받기는 아래 안내 페이지에서 하세요.

- 안내 페이지: https://sky.gyo6.kr

## 이곳에서 받는 방법

1. 위쪽 오른편의 **Releases**(릴리스)를 누릅니다.
2. 공개된 단계의 릴리스를 열고, 아래 **Assets**에서 ZIP 파일을 누르면 받아집니다.
3. 압축을 푼 뒤 `00_시작하기.html`(전체 묶음) 또는 `사용법.pdf`부터 엽니다.
